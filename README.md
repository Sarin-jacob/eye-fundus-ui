# FundusView — fundus camera UI demo

A mobile PWA mock-up of the operator UI for a smartphone fundus camera: the phone mounts onto a
3D-printed module that holds the condensing lens, an IR preview LED and a white flash LED.

This is a **UI demo**. The retina is simulated and nothing here is a medical device.

## What the demo does

- **Home**: pair the lens module (simulated BLE), enter the patient, choose the eye (OD/OS) and the pupil state.
- **Capture**
  - Live 45° view, starting in IR preview. As the phone approaches, the view goes from the anterior eye (iris/pupil) to the retina.
  - Alignment guidance: an X/Y reticle dot, a working-distance (Z) bar, and a status pill ("Move closer", "Centre on pupil →", "Adjust focus", "Aligned").
  - Focus ruler in dioptres, with an AF sweep.
  - Auto capture fires the white flash once the eye holds alignment. A pupil-recovery lockout follows for non-mydriatic exams.
  - Post-capture sheet: Retake / Capture the other eye / Review.
  - Drag the view to move the phone in X/Y. Drag the Z bar (or scroll) to change the working distance. Turn off *Assist* for fully manual alignment.
- **Review**: a gallery filtered by eye with quality scores, a full viewer with Color / Red-free / Enhance modes, share or save, and delete.
- **Settings**: image source (simulated or the phone's rear camera, with torch as the flash where the browser supports it), flash intensity, fixation target, grid, sound.

Captures are stored in `localStorage` on the device.

## Run locally

Any static server works:

```bash
python -m http.server 8765
```

Then open http://localhost:8765. The camera source needs HTTPS or localhost.

## Deploy to GitHub Pages

1. Push this repo to GitHub.
2. Go to **Settings → Pages → Build and deployment**, choose *Deploy from a branch*, and select `main` / `/ (root)`.
3. Open `https://<user>.github.io/<repo>/` on the phone:
   - Android (Chrome): use *Install app*.
   - iPhone (Safari): use Share → *Add to Home Screen*.

All paths are relative, so the app works under the `/<repo>/` sub-path.
When you ship changes, bump `CACHE` in `sw.js` so installed copies update.
